## CFD Mixing Tank – Suspension Quality Prediction

1. **Dataset:** [Kaggle: Computational Fluid Dynamics : Mixing Tank](https://www.kaggle.com/datasets/comacque/computational-fluid-dynamics-mixing-tank), based on ANSYS FLUENT RANS Euler-Granular CFD simulations with 1,014 simulation runs of a two-phase solid-liquid mechanically stirred mixing tank. It studies the impact of physical parameters (tank and agitator design, stirring speed, tank diameter, particle size, solid and fluid densities, viscosity, and solid fraction) on suspension quality. While the full Kaggle dataset includes 78 features (X1 to X8 raw physical parameters and X9 to X78 engineered dimensionless numbers), this assignment analyzes the raw physical inputs (X1 to X8) and target Y. The original study is referenced on [ResearchGate](https://www.researchgate.net/publication/327059961_Solid-Liquid_Mixing_in_Stirred_Vessels_Numerical_Simulation_Experimental_Validation_and_Suspension_Quality_Prediction_Using_Multivariate_Regression_and_Machine_Learning).
2. **Features:** 8 normalized raw physical variables (X1 to X8, scaled between 0 and 1) representing impeller/tank geometry, agitation speed, vessel diameter, particle diameter, solid/fluid densities, dynamic viscosity, and solid volume fraction.
3. **Prediction Target:** Y = RSD / 100 (Relative Standard Deviation of solid concentration), where lower values indicate uniform suspension and higher values denote settling/stagnation. Models were trained on the benchmark Design 1 configuration (534 samples).
4. **Models:** Multivariate Linear Regression (reference model), and Support Vector Regression (SVR) with an RBF kernel were evaluated. RBF Kernel was used as per the [reference](https://www.researchgate.net/publication/327059961_Solid-Liquid_Mixing_in_Stirred_Vessels_Numerical_Simulation_Experimental_Validation_and_Suspension_Quality_Prediction_Using_Multivariate_Regression_and_Machine_Learning). Although this paper has trained the dataset using over 10 models, for the current assignment I have trained the data only on models. 
5. **Results:** Linear Regression test R² = 0.07 (RMSE = 0.163); SVR test R² = 0.72 (RMSE = 0.089). When evaluated as a well-mixed vs. poorly-mixed engineering classifier (RSD <= 20%), SVR achieved 91% accuracy compared to only 59% for Linear Regression. 5-fold cross-validation confirmed consistent generalization (R² ≈ 0.72).
6. **What I Learned:** The fluid-solid dynamics of suspension are strongly non-linear; linear models severely underfit, whereas SVR with an RBF kernel captures the curvature well. However, a model trained on one impeller design does not transfer reliably to unseen designs with different hydrodynamics (e.g. hydrofoil vs. pitched-blade). Capturing generalized multi-geometry physics requires incorporating dimensionless numbers or higher-capacity architectures like Neural Networks.
